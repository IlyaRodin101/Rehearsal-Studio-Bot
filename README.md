# Telegram-бот бронирования репетиционных баз

Структура исходного проекта следует шаблону `echobot`: запуск в `ru.urfu.echobot`, Telegram-адаптер в `bot`, сценарии и SQLite в `service`.

Реализована только задача 1 из исходного описания: управление базами владельцем, бронирование залов, просмотр будущих записей и информации о базе. Отмены, горячие слоты, администраторы, напоминания и оценки не включены.

## Требования

- JDK 8 или новее (для сборки нужен именно JDK, не только JRE)
- Maven 3.6 или новее
- Telegram bot token от `@BotFather`
- Telegram ID владельца

## Сборка и запуск

В PowerShell задайте переменные окружения и запустите собранный JAR:

```powershell
$env:TELEGRAM_TOKEN = "токен_от_BotFather"
$env:OWNER_ID = "123456789"
# Необязательные настройки:
$env:BOT_USERNAME = "имя_бота"
$env:DATABASE_PATH = "database.db"

mvn test
mvn checkstyle:check
mvn package
java -jar target\echobot-1.0-SNAPSHOT.jar
```

Если `DATABASE_PATH` не задан, файл SQLite `database.db` создаётся в текущей рабочей папке. Переменные окружения нужно задать заново в каждой новой сессии PowerShell.

В Nix можно открыть окружение проекта командой `nix develop`.

## Возможности

- Владелец добавляет произвольное число баз, задаёт название, адрес, часовой пояс, расписание каждого дня недели, залы, обязательность комментария, минимальный срок до бронирования и оборудование.
- Настройки существующей базы, залов и расписания можно изменить через меню `[Базы]`.
- Клиент выбирает доступную базу, зал, месяц, неделю, день, время и длительность; вводит имя, российский номер телефона и комментарий.
- Свободные варианты учитывают расписание, срок бронирования и уже занятые интервалы.
- Подтверждение брони атомарно проверяет пересечения интервалов в SQLite; параллельные запросы на один зал и время не могут создать конфликтующие записи.
- Базы, расписание, залы и записи хранятся в SQLite и сохраняются после перезапуска.

## Проверка

`mvn test` проверяет сохранность записей и конкурентную бронь пересекающегося времени. `mvn checkstyle:check` запускает проверку стиля из `checkstyle.xml`.
